# Clínica Aurora — modelo de site institucional

Modelo responsivo para clínica multidisciplinar, criado para ser reutilizado em projetos de clientes.

## Estrutura visual
1. Hero escuro com imagem de fundo
2. Introdução em branco
3. Especialidades em tom claro
4. Sobre a clínica em cor principal
5. Profissionais em branco
6. Estrutura em neutro quente
7. Fluxo em tom escuro
8. FAQ em branco
9. CTA de contato em verde profundo
10. Footer escuro

## Personalização rápida
- Troque o nome da clínica no `index.html`.
- Substitua os números, especialidades, profissionais e conselhos.
- Troque o número `5571999999999` pelo WhatsApp real.
- Atualize `canonical`, Schema.org, sitemap e dados de contato.
- As duas imagens demonstrativas usam URLs do Unsplash. Para produção, substitua as URLs no `index.html` e `styles.css` por fotos autorizadas da clínica ou arquivos locais em `assets/`.
- Revise convênios, horários e textos regulatórios antes de publicar.

## Arquivos SEO incluídos
- `robots.txt`
- `sitemap.xml`
- `llms.txt`
- metatags Open Graph
- dados estruturados Schema.org

## Publicação
Pode ser publicado como site estático em Cloudflare Pages, Netlify, Vercel ou hospedagem convencional.
